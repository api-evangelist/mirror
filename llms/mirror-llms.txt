# Mirror Protocol

> Mirror Protocol is a decentralized finance (DeFi) synthetic-assets protocol built on the Terra blockchain (with an Ethereum bridge) that mints mirrored assets (mAssets) tracking the prices of real-world equities, commodities, and other assets. Its public developer surface is the Mirror API — a read-only GraphQL data service exposing protocol state (assets, prices, positions, staking) — plus the mirror.js SDK and mirrorcli command-line interface for querying and executing against the on-chain contracts. The protocol is governed by the MIR token and is now in a legacy/dormant state following the May 2022 Terra collapse.

## API

- [Mirror API (GraphQL)](https://docs.mirror.finance/developer-tools/mirror-api): Single-endpoint GraphQL data service. Mainnet POST https://graph.mirror.finance/graphql ; Testnet https://bombay-graph.mirror.finance/graphql . Unauthenticated. GraphiQL playground served at the endpoint.
